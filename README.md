# BASHRA Skincare

A responsive, bilingual skincare storefront prototype built with plain HTML, CSS, and JavaScript. It supports English and Arabic, remembers the selected language in the browser, and switches the page direction for Arabic.

## Preview locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository and add these project files.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The site uses relative asset paths and is ready to publish from the repository root.

## Project layout

- `index.html` — page structure
- `css/styles.css` — responsive styling
- `js/app.js` — page rendering and interactions
- `js/i18n.js` — English and Arabic UI translations
- `assets/images/` — supplied product and botanical photography

## Prototype notes

Product prices and copy are sample content. Checkout, payments, newsletter signup, and contact delivery are not connected to live services. Confirm product details, ingredients, contact information, and prices before a commercial launch.
